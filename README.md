# Oktoberfest Data Analysis

A Python-based data analysis project exploring how Oktoberfest visitor numbers, beer consumption, and beer prices have changed over the years.

## Project Objectives
- Analyze historical visitor and beer consumption trends.
- Explore relationships between attendance and beer consumption.
- Examine beer price changes and inflation.
- Estimate beer revenue based on historical data.

## Technologies
Python · Pandas · NumPy · Matplotlib · Jupyter Notebook

## Project Structure
- `notebooks/` – Jupyter Notebook containing the analysis
- `data/` – Datasets used in the project
- `figures/` – Charts and visualizations

## How to Run
1. Clone this repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Open the notebook in Jupyter Notebook.
4. Run the cells using the required datasets.
