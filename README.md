# Oktoberfest Data Analysis

## Project Overview
This project explores historical Oktoberfest data using Python to understand how the festival has evolved over time. The analysis focuses on visitor attendance, beer consumption, beer prices, inflation-adjusted beer prices, and estimated beer revenue.

## Objectives
This project is built around the following questions:

- How have Oktoberfest visitor numbers changed over time?
- How has beer consumption evolved?
- Is there a relationship between visitor attendance and beer consumption?
- How have beer prices changed over time, including after inflation adjustments?
- What can historical data tell us about estimated beer revenue?

## How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/egemenyrlmz/oktoberfest-data-analysis.git
   cd oktoberfest-data-analysis
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Open Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
4. Add the required datasets to the `data/` folder and run the analysis notebook from `notebooks/`.

## Limitations
- The analysis depends on the availability, consistency, and quality of historical data.
- Revenue values are estimates derived from historical records and assumptions, not verified financial statements.
